PC에서는 `01_프로그램/현재_게시글제작/게시글_제작과_검토` 바로가기로 작업대를 엽니다. 소재·제작·검토·게시준비를 같은 창에서 이어가며, `원문_컷편집기` 바로가기도 작업대의 제작 화면 진입점입니다. 실제 설치·바로가기 전환은 패키지 검증 후 적용합니다.

소재는 작업대의 **소재**에서 찾습니다. 요약과 본문 미확보는 제작할 원문 전문이 아니며, 같은 사연의 공개 메모를 별도 소재로 중복 집계하지 않습니다.

GitHub에는 코드·안내·공개 가능한 소재 기록을 보관합니다. 원본 사진·개인 평가·설치 본체·운영 이력은 PC의 비공개 자료로 보존하며, 폴더 정리나 새 버전 설치로 초기화하지 않습니다. 개발·검사는 [99_작업영역](99_작업영역/)에서 관리합니다.
