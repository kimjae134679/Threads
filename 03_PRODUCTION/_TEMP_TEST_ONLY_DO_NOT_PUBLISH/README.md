> **임시 테스트 전용 폴더입니다. 실사용/실게시 산출물이 아닙니다.**
>
> 이 폴더의 파일은 실제 운영용 `03_PRODUCTION` 결과물과 구분하기 위한 실험·변환 테스트용입니다.
> 승인 완료, 권리 확인, 개인정보 검수, 게시 가능, A1/P1 상태를 의미하지 않습니다.

## 목적

사용자가 제시한 실제 변환 진행표의 남은 작업을 소재 하나씩 조금씩 검증합니다.

테스트 순서:
1. 원문 자동 확보 연결 가능성 검증
2. Instagram/플랫폼 UI 제외 처리 검증
3. 길이 기준이 아닌 문단·장면 경계 기반 분할
4. 원문에 맞는 짧은 제목 제안
5. 브라우저에서 한 소재 전체 생성 → 다운로드 → 재접속/복원 검수
6. 검수 화면 연결
7. 승인본이 실제 실행 환경에 반영되는지 검증
8. 실제 게시는 **별도 명시적 승인 없이는 수행하지 않음**

## 절대 규칙

- 폴더명과 모든 결과물에 `TEMP_TEST_ONLY` 또는 `DO_NOT_PUBLISH` 표기를 유지합니다.
- 실제 후보 `data/candidates`의 C/A/P 상태를 테스트 결과만으로 승격하지 않습니다.
- 테스트 산출물을 `04_REVIEW_PUBLISH` 승인본으로 취급하지 않습니다.
- 외부 서비스 접근 제한, 로그인, anti-bot, paywall을 우회하지 않습니다.
- 원문 전체를 읽지 못했으면 요약/장면을 추정해 채우지 않습니다.
- 원본 이미지/캡처를 확보하지 못했으면 가짜 원문 이미지를 만들지 않습니다.
- 테스트용 제목/표지/분할 결과는 실제 게시본과 다를 수 있습니다.
- 실게시/성과수집 항목은 자동화하지 않습니다. 별도 사용자 승인 후 독립 검증합니다.

- 각 소재 하위 폴더: 실제 테스트 변환 산출물
