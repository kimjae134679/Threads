STEP 1

저장된 원문을 불러오세요

PC에 이미 저장한 원문 폴더나 편집 파일을 열어 이어서 작업합니다. 새 링크 수집은 필요할 때만 선택하세요.

폴더 전체 자동 제작

후보 폴더를 한 번 선택하면 하위 후보를 순서대로 검사합니다. 원본 이미지가 있는 건 검수용 이미지 ZIP을 만들고, 없는 건 보류 사유를 기록합니다. 같은 원본으로 이미 만든 건 건너뜁니다.

결과 목록은 바탕화면 Threads Cut Editor 자료/06_자동 제작 결과에 저장됩니다.

이미 저장된 자료

저장된 원문 묶음은 original, 후보 자료는 이미지가 있는 개별 후보 폴더의 media를 선택하세요. 이미지는 파일명 순서대로, 제목은 SOURCE.md 또는 manifest.json에서 가져옵니다. 이미지 없는 후보는 아직 컷을 만들 수 없습니다.

컷 편집은 원본 영역을 직접 자릅니다. 검수 이미지는 별도 창에서 같은 저장 폴더를 선택해 바로 만듭니다. 본문·댓글 확인은 자동 완료되지 않습니다.
