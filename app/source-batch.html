원문 선별·이미지 제작

PC에 저장된 원문 폴더를 열어 제목과 이미지 순서를 확인하고, 검수 전 미리보기부터 만드세요.

저장된 원문으로 시작

이미지가 있는 개별 후보 폴더(manifest.json + media) 또는 Source Package(SOURCE.md + original)를 선택합니다. 후보 요약 content.txt는 본문으로 사용하지 않습니다.

제목과 이미지만 불러옵니다. 본문·댓글·이미지 위치는 확인 전이며 게시용 제작은 잠겨 있습니다.

기존 파일 전체 작업

파일 목록을 불러오는 중입니다.

원문 HTML은 제목·본문·이미지·댓글이 분리됐다는 보장이 없습니다. 원본을 읽고 사용할 부분을 고르기 전에는 제작 완료로 표시하지 않습니다.

글 제목원문 수집선별 상태이미지확인할 내용열기
내가 가진 원문 폴더 직접 처리

저장한 원문 HTML 또는 원문 그대로의 TXT/JSON과 첨부 이미지를 선택할 수도 있습니다.

폴더를 고르면 결과를 그곳에 저장합니다. 고르지 않으면 브라우저 다운로드로 받습니다.

원본 TXT 형식과 판정 기준 
[TITLE]
원본 제목
[BODY]
원본 글 그대로. 줄바꿈과 공백을 변경하지 않습니다.
[IMAGE:photo1.jpg]
이미지가 놓인 원문 위치 바로 다음 문장
[COMMENTS]
[+123] 인기 댓글 원문
[+45] 두 번째 댓글 원문

TXT는 파일 자체가 원문일 때만 사용하세요. 기존 content.txt의 BODY_SEQUENCE 요약은 원문으로 판정하지 않습니다. HTML은 구조에 따라 공백·줄바꿈이 달라질 수 있으므로 변환 후 원문 대조 상태를 남깁니다. 인기 순위 근거가 없으면 댓글을 임의로 고르지 않습니다.

사용할 원문 선별

본문 영역의 글과 실제 파일이 있는 이미지를 순서대로 추천합니다. 페이지의 메뉴·광고·댓글이 섞이지 않았는지 원문과 대조하세요. 조각 뒤 여백과 직접 쓰는 의견은 별도로 기록됩니다.

게시 이미지 글씨 스타일

실제 댓글 선별

댓글을 사용하지 않으면 아무것도 선택하지 마세요. 인기 댓글이라는 표현은 반응 수나 BEST 근거를 확인한 경우에만 사용합니다.

기존 원문 ZIP 다시 사용

이미 저장한 ZIP을 다시 열어 수정하거나 이미지를 다시 만듭니다. 현재 열린 원문은 위 버튼에서 바로 제작할 수 있습니다.
