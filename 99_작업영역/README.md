# AI·개발 작업영역

사용자는 [프로그램](../01_프로그램/)·[자료](../02_자료/)·[참고자료](../03_참고자료/)에서 시작합니다.

| 구역 | 담당 내용 |
| --- | --- |
| [소스](소스/) | 프로그램 코드·개발 문서·테스트·설정·이전 코드 |
| 로컬보관 | 기존 PC 도구·입력·캐시·환경 설정. Git 제외 |
| 작업기록 | 이관 내역·검증 기록·소통함. 비공개 |

개발 검사는 소스 폴더에서 실행합니다. 기존에 루트에 있던 app,desktop,data,scripts,test,upload-studio,package.json과 mjs 파일은 소스 안에 실제로 이동했습니다.

기본 실행 데이터가 있는 D드라이브 통합 설치본은 독립적으로 보존합니다. 실행 위치를 추측해서 바꾸거나 사용자 평가를 초기화하지 않습니다.

현재 Git 기준은 main 한 개입니다. [브랜치·작업트리 정리 기록](소스/docs/99_과거기록/브랜치_작업트리_정리_2026-11-01.md)에 보존·정리한 항목을 남겼습니다.
