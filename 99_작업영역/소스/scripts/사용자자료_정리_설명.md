# 사용자 자료 내용 정리

organize-user-materials.py와 consolidate-user-sources.py는 이번 내용 이관의 재현용 코드입니다. 일상 실행 프로그램이 아닙니다. 원본 상태를 갱신하는 동기화 기능은 없으며, 기존 결과에 덮어쓰도록 실행하지 않습니다.

기존 현재 제작본·사용자 평가와 원자료는 변경하지 않았습니다. 사용자용 파일은 별도 복사본입니다. 실제 이미지와 보관 HTML은 SHA-256으로 대조했고, 로컬 읽기 화면의 연결도 검사했습니다.

공개 소재 메모는 이미 공개된 후보 TXT의 제목·출처·본문만 복사했습니다. 개인정보·평가·설치 본체·참고 이미지와 원자료 전체는 Git 제외입니다.
