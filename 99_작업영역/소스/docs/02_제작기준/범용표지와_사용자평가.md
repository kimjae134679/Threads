# 범용 사진 없는 표지 템플릿과 사용자 리뷰 기록

기록일: 2026-10-08 KST.

## 사용자 최신 지시

사용자는 새 리뷰를 대략 작성했다고 알렸다. 리뷰에 따른 다음 제작보다 먼저, 사진 없는 첫 표지의 디자인을 고안하도록 요청했다. 눈에 확 들어오되 과하지 않아야 한다. 60만원 사연으로 보여준 세 시안은 예시이며, 사용자는 **어떤 내용이든 범용적으로 쓰고 어떤 제목으로도 교체할 수 있는 디자인**을 요구했다. 특정 금액·소비·영수증 소재에 종속되는 틀은 최종 기준이 아니다. 이번 요청은 요구사항과 리뷰 작성 사실을 GitHub에 저장하고, 실제 저장을 확인하는 것이다.

## 범용 템플릿의 설계 기준

- 기본 구조는 사진 없는 타이포그래피 표지다. 제목이 주인공이며 밝은 단색 바탕, 짙은 글자, 강조색 하나, 충분한 여백을 사용한다.
- 바뀌는 입력은 제목 원문과 선택적 강조 구절이다. 금액·숫자·이미지·카테고리가 없어도 완성된 표지가 나와야 한다.
- 일반 제목, 숫자 없는 제목, 짧은 제목, 긴 제목 모두 같은 디자인 체계에서 처리한다. 주제별 장식보다 글자 길이와 줄 수에 맞춘 배치 변형을 사용한다.
- 제목의 의미 단위에 따라 줄을 나누고 중요도에 맞게 두 수준의 글자 크기를 둔다. 모든 줄을 최대 크기로 만드는 방식은 피한다.
- 강조는 핵심 1~2곳에 한정한다. 강조 구절이 없으면 기본 제목 배치로 완성한다. 숫자가 있다고 무조건 숫자만 크게 만들지 않는다.
- 짧은 제목은 크게 배치하고 여백을 확보한다. 긴 제목은 안전 영역에서 줄바꿈과 제목 영역을 먼저 조절하고, 읽을 수 있는 최소 크기 아래로 억지 축소하지 않는다. 필요하면 긴 제목용 배치로 전환한다.
- 제목은 임의로 잘라내거나 말줄임표로 숨기지 않는다. 원문에 없는 자극적인 표현이나 사건·반응을 추가하지 않는다.
- 기존 출력 규격 1080×1920과 안전 여백을 유지하고, 실제 작은 화면에서도 읽히는지 확인한다. 앞서 생성한 가로 비교 보드는 개념 시안이며 제작용 최종 PNG가 아니다.
- 영수증·금액 전용 틀, 가짜 반응·좋아요·프로필, 이모지, 과한 테두리·그림자·효과를 범용 기본형에 넣지 않는다.

## 구현 후 확인할 항목

짧은/중간/긴 제목, 숫자 없음/있음, 강조 없음/1곳/2곳, 한글과 영문 혼합, 따옴표·괄호·문장부호가 있는 제목으로 교체해 검사한다. 제목 누락·겹침·잘림·안전 영역 침범이 없어야 한다. 가장 긴 실제 제목과 줄바꿈이 까다로운 실제 제목도 포함한다. 디자인을 확정해 구현한 뒤 실제 전체 재생성과 재검토를 진행한다. **이 문서 기록 시점에는 범용 디자인 구현이나 전체 재제작이 완료된 것이 아니다.**
