# 검토 앱 켜기 · 끄기 · 화면 열기

통합 관제탑의 **인스타 수익화 · 콘텐츠 제작 → 새 제작물 검토 앱 · 켜기 / 열기 / 끄기**에서 원하는 항목을 선택하고 오른쪽 **등록 작업 실행** 버튼을 누릅니다. 현재 관제탑의 기존 실행 버튼을 재사용하며, 새 독립 버튼 줄을 추가한 UI 버전은 아닙니다.

- 검토 앱 켜기: 로컬 서버를 숨겨 시작합니다. 이미 같은 서버가 정상 응답하면 재사용합니다. 브라우저는 별도로 엽니다.
- 검토 화면 열기: 켜진 서버의 화면을 기본 브라우저에서 엽니다. 꺼져 있으면 켜기부터 실행하도록 안내합니다.
- 검토 앱 끄기: PID·명령 인수·4387 포트 소유자가 일치하는 서버만 중단합니다. 제작물, 판정, 기존 게시 결과를 보존합니다. 자동 제작 연결도 서버와 함께 멈춥니다.
- 검토 앱 실행 상태: 선택 중에 실행 주체와 실제 응답을 확인합니다.

실행 중인 통합 앱은 일반 프로젝트 등록을 자동으로 다시 읽지 않는 수동 모드입니다. 등록 파일은 설치했으며, 현재 열린 0.9.18 화면은 반복 상태 조회 때문에 정상 종료 요청이 `held_jobs`로 보류됐습니다. 강제 종료하지 않았습니다. 이번 사용자 요청의 기존 ‘작업이 끝나면 자동 연결’ 지시에 따라 한 번만 실행하는 유휴 적용기를 시작했습니다. 3초마다 새 상태를 읽고 연속 두 번 유휴인 경우에만 정상 종료 요청 후 기존 설치 런처로 다시 엽니다. 30분이 지나거나 응답/신원이 불명확하면 중단하며 강제 종료·반복 종료 요청은 하지 않습니다. 실제 메뉴 렌더링과 버튼 클릭은 아직 미검증입니다.

PC 확인 파일: `D:\A_KJ\AI\Scripts\ThreadsUploadStudio\menu-activation.json`. `waiting_idle`은 화면 반영 완료가 아닙니다. `restarted`도 새 프로세스·연결 확인이며 버튼 클릭 검증과 구분합니다. 다음 앱 시작이나 도구·연결의 프로젝트 상위 폴더 재선택으로도 등록 목록을 다시 읽을 수 있습니다.
