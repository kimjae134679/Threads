# 남친이나 남편이 세차모임 자주 나가서 걱정이신가요?

- 상태: C0 / A0 / P0
- 출처: Inven 공개 인기 인덱스
- 정확한 개별 원문 링크: 미확인
- 확인된 인덱스: https://webzine.inven.co.kr/
- 조회수/좋아요/댓글: 개별 글 수치 미확인
- 본문: 전체 미확인

## 글 내용
공개 인기 인덱스에서 제목 노출만 확인했다. 세차모임에 자주 나가는 연인을 걱정하는 생활형 연애/결혼 소재로 보이지만 개별 본문을 읽지 않았으므로 세부 내용을 임의로 채우지 않는다.

## 평가
- 평가: 검증 대기
- 이유: 연인의 취미 모임을 둘러싼 불안/갈등은 의견 참여 가능성이 있음.
- 다음: 정확한 개별 게시물 URL과 본문/반응 수치를 확인해야 C1 가능.
- 제작: ASSETS_PENDING / publicationAllowed=false
