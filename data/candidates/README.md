# 후보 한 건 = 파일 하나

이 폴더가 사람이 보는 기본 Discovery 목록이다. 파일명만 봐도 날짜/후보단계/자산생성/게시상태를 알 수 있다.

- `C0`: 제목은 찾았지만 정확한 개별 원문 URL 또는 provenance가 아직 부족함
- `C1`: 정확한 원문/공개 URL을 확인함
- `C2`: 제작 후보로 선택됨. rights/privacy/human approval은 별도
- `A0`: 실제 source-backed 이미지/캐러셀 미생성
- `A1`: 실제 source asset 기반 사용자용 결과물 생성 확인
- `P0`: 미게시
- `P1`: 04가 실제 게시 성공 확인

후보 파일 안에는 **제목 / 확인된 글 내용 요약 / 정확한 링크 / 동일 시점 관측 수치 / 평가 / 자산·게시상태**만 중심으로 적는다. 개발용 schema나 프로그램 코드 설명은 넣지 않는다.
