# AI도 고집이 엄청나군요.

## 글 내용
공개 index에서 이미지의 마지막 줄 `그대료`를 `그대로`로 고쳐 달라고 30번 넘게 요청했는데 AI가 계속 제대로 수정하지 않았다는 사용자 경험담을 확인했다. 2026-09-20 재검색에서도 같은 제목/문구가 공개 인덱스에 노출되는 것은 재확인했지만, 정확한 개별 원문 URL/고유 게시물 ID는 특정하지 못했다.

## 정확한 링크
정확한 개별 원문 URL 미확인. 공개 검색/index에서 부분 본문 확인.

## 관측 수치
- 최초 관측: 2026-09-16 14:34 KST 부근
- provenance 재검색: 2026-09-20 03:27 KST 부근
- 조회/좋아요/댓글 미확인
- 본문 읽음: index 노출분 확인, 전체 원문 미확인
- 댓글 읽음: 아니오

## 평가
AI 이미지 글자 수정 실패를 매우 단순하고 웃기게 보여주는 공감형 소재다. 실제 실패 이미지가 확보되면 시각적으로 강하다.

## 형식
이미지 추정

## 이미지·자산 / 제작·게시 상태
- exact individual source: 미확인
- source 파일 확보: 아니오
- acquisition: BLOCKED_PROVENANCE / ASSETS_PENDING
- C0 / A0 / P0
- publicationAllowed=false
- unblockWhen: 이 소재의 정확한 개별 원문 URL/고유 게시물 ID 또는 동일 게시물임을 입증하는 신뢰 가능한 고유 식별자가 공개적으로 확인될 때
- 공개 인덱스 문구만으로 전체 본문·댓글·수치·이미지·OCR/vision·권리 상태를 추정하지 않음
- rights/privacy/human review 필요
