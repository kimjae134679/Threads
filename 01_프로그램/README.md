| 99_이전버전 | 이전 설치본·실험 버전의 보존 기록 |

`현재_게시글제작/게시글_제작과_검토`로 엽니다. 소재 → 제작 → 검토 → 게시준비를 같은 창에서 이어가고, 원문 선별과 이미지 컷 편집은 선택한 글의 격리된 제작 화면에서 엽니다. `원문_컷편집기`도 별도 도구가 아닌 작업대 제작 진입점으로 연결합니다.

현재 지정 설치본은 `0.3.40-studio.20261117.2`입니다. 패키지 normal·읽기 전용 실행과 실제 운영자료 읽기를 검증했고, C의 실행 바로가기와 `프로그램본체` 연결을 D 운영루트의 .2 설치본으로 전환했습니다. `원문_컷편집기`는 같은 작업대의 제작 화면을 엽니다. 이전 본체·원자료·평가는 보존합니다.

GitHub에는 소스·용도·공개 기록을 보관하고, 큰 EXE/resources와 PC 바로가기는 포함하지 않습니다. 실제 게시·예약은 검토나 점수 저장과 별도이며 현재 실행하지 않습니다.
