새 제작본을 기다리고 있어요

현재 승인된 인터넷 리뷰 서버가 없어 게시글을 자동 수신할 수 없습니다. 서버 연결이 준비되면 앱을 열 때 최신 글과 이미지를 받습니다.

받은 글의 평가와 메모는 오프라인에서도 보존됩니다. 사용자가 파일을 넣을 필요는 없습니다.

아직 글 수신 · 서버 평가 전송은 실행되지 않았습니다.

이 기기에 저장된 작업

대기 중인 평가는 서버 반영과 구분됩니다. 충돌 시 양쪽 기록을 확인하고 선택하세요.

GitHub 연결 준비

공식 device 로그인과 기기 Keystore 보호 코드가 준비됐습니다. 브릿지·PC 명령 저장소와 분리된 전용 비공개 리뷰 저장소, GitHub App 설치와 사용자 승인이 아직 없어 실제 연결되지 않았습니다. 로그인·키/토큰 생성·업로드는 비활성입니다.

연결 상태

인터넷 리뷰 서버 미연결

자동 수신 기능 연결 전의 Android 준비판입니다. 현재 PC 서버와 브릿지는 인터넷 리뷰 서비스가 아니며 이 앱은 해당 인증정보를 포함하지 않습니다.

승인된 HTTPS 리뷰 서비스와 사용자 인증 경로가 없어 실제 온라인 동기화는 연결되지 않았습니다. Android의 일반 인터넷 선언 자체가 금지된 것은 아닙니다.

평가는 제작본별로

글 ID · 제작 버전 · 검토 회차가 바뀌면 새 평가는 빈 상태로 시작합니다. 옛 작업은 새 제작본에 전송되지 않습니다. 카테고리와 테마는 자동 적용됩니다.

게시 승인 체크는 검토 의사 기록입니다. 실제 게시 기능은 이 APK에 없으며 어떠한 글도 게시하지 않습니다.
