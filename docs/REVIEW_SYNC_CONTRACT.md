# PC 리뷰 저장과 향후 모바일 연결 계약

현재 동작은 PC 로컬 저장입니다. APK, 동기화 서버, 계정 연결 또는 새 포트는 이번에 만들지 않았습니다. 모바일은 PC 핵심 기능 안정화 후 진행합니다.

평가 식별은 글 ID + outputVersion(원본 지문·제작물 해시·규칙 버전·검토 회차 포함)입니다. 점수/메모는 평가 기록.json, 본 페이지와 마지막 페이지 및 보류/탈락/복원 이력은 검토 진행.json에 나눠 저장합니다. 수정된 제작본의 옛 점수를 새 버전으로 복사하지 않습니다. 게시 승인은 별도 명시적 사용자 승인 필드와 이벤트로 설계하며 점수로 유도하지 않습니다.

향후 모바일은 게시글 버전 manifest를 내려받고 표지부터 끝까지 표시합니다. 오프라인 작업은 operationId, 글 ID, outputVersion, reviewRound, baseRevision, 작업 종류, payload, 기기/작성 시각으로 큐에 저장합니다. 서버는 operationId 중복 방지와 revision 비교를 적용하고 충돌을 사용자에게 보여야 합니다. 무조건 마지막 쓰기로 덮어쓰지 않습니다. 새 버전은 별도 빈 평가와 진행을 만듭니다. 보류/수정 필요/게시 승인 상태는 서로 다른 의미를 유지합니다.

평가 기준은 기준 버전과 함께 전달합니다. 임의 계정 권한이나 개인 이메일/연락처를 동기화 인증 수단으로 사용하지 않습니다. 실제 권한·전송 목적·서버 배치는 추후 사용자 승인 범위에서 결정합니다.
