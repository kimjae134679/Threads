AAA 원본의 `humor_saul`은 현재 정확한 프로필 주소에서 페이지 사용 불가가 표시되었다. 봇 차단으로 단정하지 않았다. 기존 AAA 20–22번 보관 이미지를 분석 근거로 유지한다. `humor_saul`과 `humor_ssul`은 서로 다른 계정이다. 사용자 브라우저의 9개 탭 중 나머지 1개의 주소는 연결에 전달되지 않아 임의로 추정하지 않았다.

원본 이미지·캡션 아카이브는 사용자 자료로 별도 보관한다. 이 공개 저장소에는 제작 기준과 구현 명세를 두며 제3자 게시물 원본을 새로 게시하지 않는다.

## 형식 선택

| 실제 관찰 | 제작에 적용할 결정 |
|---|---|
| 모아보기의 사진 표지와 하단 그라데이션·흰 제목 | 관련 원본 사진이 사건을 설명하면 사진 표지를 선택한다. 제목은 피사체를 덮지 않는 영역에 놓는다. |
| 썰 계정의 민트 배경과 큰 검정 제목 | 관련 사진이 없는 글은 큰 제목 표지를 선택한다. 제목 다음 장부터 사건을 전개한다. |
| 배꼽박스의 흰 바탕과 굵은 외곽선 제목 | 짧은 경험담은 흰 바탕 제목으로 시작할 수 있다. 외곽선을 과하게 넣어 가독성을 떨어뜨리지 않는다. |
| 익판의 원문 화면·강조 제목과 후속 설명 | 표지 이후에 원문을 확대해 읽게 한다. 원문 제목을 표지와 본문에서 불필요하게 반복하지 않는다. |
| 역사 계정과 최 계정의 설명·사진·방송 프레임 | 설명 문단과 관련 이미지를 묶는다. 사진만 저장하고 실제 내용이 담긴 긴 캡션을 빠뜨리지 않는다. |

수치는 실제 레퍼런스 폰트 측정값과 추천 조판값을 구분한다. 현재 권장 시작값은 폭 1080, 안전 여백 64, 사진 표지 제목 64–84, 본문 46–54px이다. 글자를 줄여 한 장에 밀어 넣기보다 읽는 단위를 나눈다.

Threads에서는 내용에 맞춘 높이를 사용한다. Instagram용 같은 게시물의 일정한 비율은 별도 조판 모드로 구현해야 한다. 가로 사진을 세로로 늘리거나 내용 없는 큰 공간을 붙여 비율만 맞추지 않는다.

## 수집 단계에서 확정할 제작 계획

원문 URL·게시 시각·확인 시각·수집 시각, 원제목, 표지 제목과 근거 문단, 자료 종류, 템플릿 선택 이유, 문단·이미지 순서, 장별 목적, 생략 이유, 개인정보 검수, 제작·검수·게시 상태를 기록한다. 확인할 수 없는 게시 시각이나 게시 여부는 null 또는 unknown이다.

원문 문단과 이미지에 ID를 부여하고 각 장에 실제 사용할 ID와 이미지 분할 영역을 연결한다. 질문과 답변, 발단과 결론을 읽는 단위로 묶는다. 작성 의견은 원문 사실이나 실제 댓글과 분리한다. 광고·추천 링크·앱 UI는 보관 원본에서 식별하고 새 제작물 본문에 섞지 않는다.

스터디카페 사례의 연락처와 QR, 익판의 원문 가림과 반복 제목, 라면 댓글 장의 큰 빈 공간은 그대로 따라 하지 않을 실패 사례다. 원본은 보존하고 공개용 복사본을 검수한다. 현재 자동 개인정보 가림이 구현된 것으로 기록하지 않는다.

## 현재 구현과 추가 작업

현재 프로그램은 저장된 HTML·명시적 원문 TXT/JSON·실제 이미지를 읽고 제작 계획을 먼저 저장한 뒤 PNG를 만든다. 원문과 결과의 해시가 일치하면 재제작을 건너뛰고, 원문이나 이미지가 없으면 구체적인 보류 사유를 기록한다. URL 표시 제거·중복 처리·긴 이미지 분할·내용에 맞춘 높이는 구현되어 있다.

사진·민트·흰 바탕·캡처·설명형 선택과 Instagram 4:5·3:4 조판을 0.3.3에 구현했다. 문단·문장과 이미지 빈 줄에 따른 분할 및 실제 샘플의 모바일 크기 검수를 수행했다. 픽셀 분석은 전체 의미 판단이나 OCR을 대신하지 않는다. `reference-production-rules.json`은 분석 시점의 제안 명세이며 현재 앱이 자동으로 가져오는 설정 파일이 아니다. 현재 구현·검증 범위는 `SOURCE_CUT_DESKTOP.md`를 따른다.

현재 실제 후보 1,084개 중 검수 전 결과 417개·PNG 2,886장을 생성했다. 667개는 원문·접근·정확한 주소·미디어 등 이유로 보류된다. 생성 완료는 사실 검증·권리 검토·실제 게시 완료가 아니다. 전체 결과의 해시·크기·여백·제목 겹침·본문 URL 감사와 재실행 건너뛰기를 검증했다.

## 통과 조건

제목을 360px 미리보기에서 즉시 읽을 수 있어야 한다. 본문은 확대 없이 읽거나 원문을 확대 분할해야 한다. 핵심 대상과 글자는 안전 여백 안에 남아야 한다. 각 장에 새로운 내용이 있고 필요한 원문 영역과 결론이 빠지지 않아야 한다.

빈 장·링크만 있는 장·의도 없는 같은 문단과 이미지 반복·광고 섞임·문장과 말풍선 중간 절단은 실패다. 원문 부족은 자료를 보충하고, 가독성 실패는 장 구성과 배치를 바꾼다. 글자 축소로 문제를 숨기지 않는다.
