# 현재 자료 전체의 .3 실제 재제작

최종 사용자 지시는 기존 현재 자료 전체를 수정된 프로그램으로 다시 만들고 리뷰와 최신 결과만 제공하는 것이었다. 앞선 세 글 완료와 전체 완료를 구분했다. 현재 결과 365개 중 앞서 실제 `.3` 프로그램 출력이 3개였고, 미재제작 361개와 이미지 원본 대기 1개가 있었다.

남은 361개를 `0.3.28-cover.20261009.3` 설치 EXE의 `--cover-reproduction-request=<절대 요청 JSON>`으로 새로 출력하고 같은 리뷰 회차의 현재 결과로 연결했다. 최종 결과는 **364/365개 실제 .3 재제작 완료**, **1개 원본 대기 보류**다. 보류 글은 `source-be8fbf58dc2254`이며 기존 출력은 보존했다. 완료된 361개는 모두 이전 PNG와 픽셀이 다르다. 이전 PNG를 새 프로그램 출력으로 재표시하지 않았다.

프로그램 소스 기반은 `c67959529e032b9a71fabbab9298967677e6d0e8`, 설치 경로는 `D:\A_KJ\AI\Applications\ThreadsProduction\0.3.28-cover.20261009.3\Threads Cut Editor.exe`다. app.asar SHA256은 `fb8ea7c1c0470f17e784406216aa275a0b6fd8bba9c1af28b7e13dd87d3ef31d`다. 설치 실행은 packaged=true와 실제 EXE 경로를 기록했다. 패키지 물리 파일 해시를 Electron `original-fs`로 읽는 초기 오류를 고친 뒤 실제 361개 출력을 검증했다. 실패 패키지도 복구보관했다.

361개 원제 각각에서 상황·대상·행동을 나타내는 연속 구절을 입력으로 지정했다. 원제에 없는 문구나 세 예시의 특정 구절을 다른 글에 복제하지 않았다. 공통 렌더러에 글 ID 예외를 넣지 않았다. 한글 단어·원제 전체를 유지했고 줄을 넘는 색 구절도 유지한다. 기존 원문 사진 7개와 이미 승인된 신입사원 A 원본을 해당 기존 글에서 SHA 검증하여 보존했다. 신규 사진 선택·AI 생성·새 소재 수집은 하지 않았다.

`cover-reproduction-run.cjs`는 현재 status에 존재하고 요청의 oldRow와 일치하는 기존 결과만 복제한다. 제목 입력·현재 원문 ZIP·이미지·자산 해시를 검증하고 결과·작업 폴더를 원본과 분리한다. 새 제작 입력의 image-requirements 보류를 우회하는 새 수집 경로가 아니다. 기존 결과 재제작만 지원한다. 한 프로세스·한 락으로 처리하고 각 글의 새 PNG, 계획, preview ZIP, fingerprint, 실제 runtime, 완료 시각과 선택 입력을 체크포인트에 기록한다. 실패는 글별 held로 기록한다.

현재 결과 적용은 canonical writer 아래 10개 이하의 짧은 트랜잭션으로 진행했다. 매번 최신 status/pointer/평가/열람을 읽고 원본·새 결과 SHA를 확인한 뒤 이전 결과를 `05_이전 작업/표지 개별 수정/installed-rest-reproduction-20261009`에 보관했다. 실패 시 파일·status·pointer를 복구한다. 평가와 열람 기록은 수정하지 않았다. 이 361개에서 본문 PNG 2,679장과 본문 계획·source ZIP 원본 바이트·ZIP의 다른 항목을 보존했다. 앞선 세 글의 본문 23장까지 재제작 완료 대상의 본문은 총 2,702장이다.

사용자 최신 요청대로 `post-review-store.cjs`의 현재 `seenAt`은 현재 출력버전의 실제 progress만 사용한다. 과거의 실제 열람은 `previousSeenAt`과 기존 workflow/history에 남긴다. 평가·메모를 지우거나 새 버전에 점수를 이식하지 않는다. current result 재조회 시 이번 361개 새 버전은 전부 안읽음이었다. 이후 사용자 열람에 따라 바뀌는 값이다. 이미지 작업 큐의 과거 소재 제외 정책은 변경하지 않았다.

사용자 실행은 기본값과 두 canonical 바로가기 모두 리뷰 전용이다. 실제 새 설치를 인자 없이 실행해 `Threads 게시글 평가` 창과 HWND를 확인했다. 이전 링크 원본·SHA·복원맵은 보관했다. 기존 설치·리뷰 UI 소스는 보존했다. 리뷰 HTML/JS/CSS는 기존 설치와 바이트 일치, loader는 줄바꿈만 다르고 내용은 일치한다. 리뷰 UI 파일 자체는 편집하지 않았다.

사용자 결과 페이지는 `자료/06_자동 제작 결과/최신 표지 결과.html`이다. 재제작된 실제 364개만 제목 검색과 표지 링크로 제공하고 보류 1개를 표시한다. 과거의 세 글 전용 페이지는 이 최신 전체 페이지로 안내한다. 사용자 안내는 리뷰와 최신 결과만 노출한다.
