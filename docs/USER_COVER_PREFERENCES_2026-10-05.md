사진·도표·캡처가 있으면 우선 활용한다. 글이 있는 이미지 위에 제목을 덮지 않고 진녹색 제목 영역을 아래에 둔다. 음식 등 사진은 피사체를 살린 전체 사진·그라데이션·노란 강조를 쓴다. 사진이 없는 표지는 민트 바탕·진녹색 강조·작은 디자인 요소로 구성한다. 본문 배경은 가독성을 따라 별도로 정한다.

이미지는 원문에서 확보한 것을 쓴다. 사용자가 고른 장식 사진은 가능하지만 실제 사건 현장이나 실제 당사자 사진이라고 주장하지 않는다. 외부 그림을 임의로 만들거나 unrelated 자료를 실제 원문처럼 삽입하지 않는다. 제목은 원문에 있는 사실·감정에 근거한다. 본문 금액·띄어쓰기·줄바꿈·이미지 순서와 실제 인기 댓글을 보존하며, 후보 요약을 원문으로 처리하지 않는다.

20건 비교 화면은 이전 왼쪽·이전 오른쪽·이번 반영을 제공한다. 생성·자동 감사 통과와 전체 장의 시각 검수·사용자 만족은 구분한다. 후속 작업은 이 기준을 다시 뒤집지 않고 보류 원문 확보와 작은 캡처 가독성을 개선한다.
