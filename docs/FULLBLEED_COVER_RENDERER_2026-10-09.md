# 현재 표지 렌더러 기준

사용자 지시로 표지 공통 함수와 기존 결과 재합성 실행 경로를 변경했다. 기본 글꼴은 제공된 SB_Aggro_B 실제 파일이고, 흰 기본 글씨와 #F2E34C 핵심 구절 색 강조, 구절 내부 단어의 3% 크기 강조를 사용한다. 같은 줄의 베이스라인을 맞추고 글꼴 자체의 굵기를 사용하며 외곽선으로 굵기를 대신하지 않는다.

사진은 전체 캔버스에 cover로 채운다. 2026-10-09.7부터 제목을 하단 20% 높이 안에서 맞추고 실제 글자 바운딩 박스 위 8px부터 아래 8px까지에만 검정 불투명도 85%를 적용한다. 전환 구간은 그 위 5.5% 높이이며 최소 64% 지점 아래에서 시작한다. 제목 뒤 85% 구간은 전체 높이 22%를 넘으면 보류하고, 그 아래는 캔버스 끝까지 20% 불투명도로 낮춘다. 높이 55%, 65%, 70%, 80%, 95% 샘플 픽셀을 원래 사진과 해당 위치의 계산된 불투명도로 비교한다. 사진의 중앙 크롭과 사람을 변경하지 않는다. 제목 전체를 보존하고 단어 중간 줄바꿈과 잘린 글자는 보류한다.

AI 자산은 사용자가 지정한 `자료/AI 생성 원본`의 활성 `생성 기록.json`과 실제 PNG만 사용한다. 글 ID, 원문 제목, 생성 기록 SHA, PNG SHA 및 크기를 확인한다. 다른 위치의 이전 AI 자산을 재사용하지 않는다. 생성 요청이나 새 API는 실행하지 않는다. 최신 사용자 지시에 따라 대응 이미지가 없는 글은 제작 대기다. 글씨형 대체를 만들거나 현재 결과에 노출하지 않는다.

실행은 설치 프로그램의 `--cover-reproduction-request=<절대경로 JSON>` 경로다. 소스, 출력, 작업 폴더는 서로 분리한다. 실행 잠금, 원본·평가 및 본문 보존, 체크포인트, 실패 보류, 실제 자산·글꼴 SHA와 레이아웃을 포함한 fingerprint를 유지한다. 결과 교체는 기존 canonical writer 잠금 아래 수행하고 과거 결과를 보관한다. 기존 평가와 회차를 유지하며 교체된 현재 outputVersion만 안 읽음 상태가 된다.

글꼴은 사용자 제공 SBX_AGGRO_FONT_2026.zip의 Windows_TTF/SB_Aggro_B.ttf다. SHA256은 `6c2d664601dc6684676329577c7dd28fb6295fd488f97220b245ca72b82fc14e`. 설치 파일 SB_Aggro.ttf와 바이트가 같다. 내부 PostScript 이름은 SBAggroB, 영문 패밀리는 SB Aggro Bold다. 함께 보존한 SB_Aggro_Font_license.pdf는 프로그램 내 폰트 탑재를 허용하는 원본 안내다. 사용자는 실제 글꼴 파일을 변경하지 않았으며 렌더러는 파일 로드 실패 시 보류한다.

짧은 제목·수동 두 줄 제목·현재 적격 이미지 중 최장 48자 제목 등 대표 4장 실제 PNG와 글꼴 로딩·색·하단 픽셀 확인을 수행한다. 전체 처리 수와 설치/리뷰 등록 완료 여부는 실제 실행·교체 기록으로 별도 보고한다. 전체 완료를 이전 디자인의 처리 수로 대신하지 않는다.

실제 .6 렌더러로 365개가 출력됐으나 이후 이미지 필수 지시에 따라 현재 결과를 다시 제한했다. 원본 PNG·생성 기록·글 ID·제목·해시를 재검증한 199개만 현재 제작물이며, 대응 이미지 없는 166개는 원문·본문·평가와 함께 복구 가능한 보관 위치로 분리했다. 기존 본문 2,708장과 평가/검토 회차는 보존했다.

제작 실행별 `work/production-batch.json`은 request SHA, 배치 ID, 차수, 시작 시각을 저장한다. 같은 작업의 재개는 같은 배치를 사용하고 다른 작업은 새 ID와 다음 차수를 받는다. 배치 ID는 제작 fingerprint에 들어가며 기존 글 ID, outputVersion, 배치 ID를 별도로 유지한다. 결과/production-plan/checkpoint에 productionBatch를 전달한다. 등록 담당은 `changed.productionBatch`를 그대로 현재 status 행에 유지해야 한다. UI는 기존 현재 결과에서 유효한 AI 이미지 제작물만 묶으며 불합격 옛 스타일 보관물을 다시 노출하지 않는다.

프로그램은 제작 묶음별 썸네일 뷰어로 시작한다. 최신 묶음을 펼치고 이전 묶음을 접으며, 카드의 평가하기와 평가 상단 뷰어로 돌아가기로 같은 창에서 왕복한다. 돌아가기 전에 기존 저장 큐와 열람 큐 완료를 확인하고 실패 시 메모/평가 화면을 유지한다. 펼침·선택·스크롤을 유지하고 저장 상태를 두 위치에 표시한다. 사용자 지정 불필요 관리 버튼/내부 회차 문구는 표시하지 않는다.
