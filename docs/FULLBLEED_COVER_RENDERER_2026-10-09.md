# 현재 표지 렌더러 기준

사용자 지시로 표지 공통 함수와 기존 결과 재합성 실행 경로를 변경했다. 기본 글꼴은 제공된 SB_Aggro_B 실제 파일이고, 흰 기본 글씨와 #F2E34C 핵심 구절 색 강조, 구절 내부 단어의 3% 크기 강조를 사용한다. 같은 줄의 베이스라인을 맞추고 글꼴 자체의 굵기를 사용하며 외곽선으로 굵기를 대신하지 않는다.

사진은 전체 캔버스에 cover로 채운다. 높이 40%부터 검정 그라데이션을 시작하고 62%에서 불투명도 85%에 도달한 뒤 하단까지 85%를 유지한다. 실제 렌더의 높이 65%, 80%, 95% 픽셀을 사진 원래 픽셀과 비교한다. 제목 전체를 보존하고 단어 중간 줄바꿈과 잘린 글자는 보류한다.

AI 자산은 사용자가 지정한 `자료/AI 생성 원본`의 활성 `생성 기록.json`과 실제 PNG만 사용한다. 글 ID, 원문 제목, 생성 기록 SHA, PNG SHA 및 크기를 확인한다. 다른 위치의 이전 AI 자산을 재사용하지 않는다. 생성 요청이나 새 API는 실행하지 않는다. 이미지가 없는 글은 어두운 글씨형으로 제작한다.

실행은 설치 프로그램의 `--cover-reproduction-request=<절대경로 JSON>` 경로다. 소스, 출력, 작업 폴더는 서로 분리한다. 실행 잠금, 원본·평가 및 본문 보존, 체크포인트, 실패 보류, 실제 자산·글꼴 SHA와 레이아웃을 포함한 fingerprint를 유지한다. 결과 교체는 기존 canonical writer 잠금 아래 수행하고 과거 결과를 보관한다. 기존 평가와 회차를 유지하며 교체된 현재 outputVersion만 안 읽음 상태가 된다.

글꼴은 사용자 제공 SBX_AGGRO_FONT_2026.zip의 Windows_TTF/SB_Aggro_B.ttf다. SHA256은 `6c2d664601dc6684676329577c7dd28fb6295fd488f97220b245ca72b82fc14e`. 설치 파일 SB_Aggro.ttf와 바이트가 같다. 내부 PostScript 이름은 SBAggroB, 영문 패밀리는 SB Aggro Bold다. 함께 보존한 SB_Aggro_Font_license.pdf는 프로그램 내 폰트 탑재를 허용하는 원본 안내다. 사용자는 실제 글꼴 파일을 변경하지 않았으며 렌더러는 파일 로드 실패 시 보류한다.

대표 3장 실제 PNG와 글꼴 로딩·색·하단 픽셀 확인을 수행한다. 전체 처리 수와 설치/리뷰 등록 완료 여부는 실제 실행·교체 기록으로 별도 보고한다. 전체 완료를 이전 디자인의 처리 수로 대신하지 않는다.
