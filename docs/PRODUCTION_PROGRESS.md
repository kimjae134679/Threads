# 인스타 게시물 이미지 제작 진행표

2026-09-19 KST. 기준: 검토 중인 Threads PR #1. 목표 결과물은 **원문 이미지 또는 원문 글 → 짧고 큰 제목 표지 + 원문 전체 본문 이미지 → 사용자 검수 → 게시**입니다.

아래 숫자는 명시한 체크리스트의 완료 개수입니다. 전체 프로젝트 공수나 운영 완성률을 뜻하지 않습니다. 기존 소재 목록·평가·저장·승인·게시 adapter·성과 모델은 존재하지만, 새 원문 이미지 제작 흐름의 실제 운영 완료로 합산하지 않습니다.
