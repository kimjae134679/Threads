# Threads Cut Editor 자체 점검 (2026-09-29)

## 판정

현재 결과를 AAA.zip과 동급의 게시 품질로 판정하지 않는다. 실제 원문 이미지 8장을 사용한 검수 전 예시만 만들었다. 본문 전문, 이미지 위치, 댓글, 권리·개인정보 확인이 남아 있어 게시 승인은 false다.

## 남은 자료 상태

- 후보 1,084건 중 원본 이미지가 첨부된 것은 1건(8장), 나머지 1,083건은 이미지가 없다.
- 56건은 원문 주소도 없어 출처 확인이 필요하다.
- content.txt는 후보 요약 기록이며 본문 원문이 아니다. 이미지·본문·댓글을 추측하거나 임의로 채우지 않는다.
- AAA.zip은 22장의 스타일 참고 화면이다. 게시 순서와 정확한 원문 텍스트를 그 ZIP에서 추정하지 않는다.
- 검수 전 예시 9장은 형식과 렌더링만 점검한다. 원문 대조와 게시 승인 완료를 의미하지 않는다.

검증: 173개 JavaScript 구문 검사, 57개 테스트 묶음, 편집기 smoke, 실제 8장 원문으로 9장 검수 ZIP 생성, Windows 0.2.6 ZIP 배포를 통과했다. 표지 위 글씨는 아직 원본 인물 일부와 겹친다. AAA.zip과 동급이라고 주장하지 않는다.

## 다음 완료 기준

1. 사용하려는 개별 후보의 원문 글·이미지·댓글을 순서와 위치까지 실제 자료로 확보한다.
2. 인물·UI·자막과 새 제목이 겹치지 않는지 모든 장을 눈으로 검수한다.
3. 권리·개인정보와 게시 허용 상태를 별도 책임자가 확인한다.
4. 그때 최종 PNG ZIP을 게시 결과로 판정한다.
