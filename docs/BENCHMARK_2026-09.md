## 2. Threads에서 공식적으로 확인되는 핵심

Meta가 공개한 Threads creator insights에서 확인되는 초기 운영 원칙:

- **Replies가 매우 중요함**: Meta는 replies가 Threads view의 거의 절반을 차지한다고 설명함.
- **빈도와 노출이 연관됨**: audience build를 원하면 주 2~5회 이상 게시를 권장한 바 있음.
- **유머가 강함**: funny content가 더 많은 views를 받는 경향.
- **사진/영상/캐러셀에는 텍스트 맥락을 붙이는 편이 유리**: text가 포함된 photo/video/carousel이 평균적으로 더 많은 views.
- **텍스트 + 영상 조합도 유효**.
- **대화를 일으키는 게시물이 추천될 가능성이 높음**.
- **상위 creators는 Threads용 original content를 직접 만듦**.
- **Topic tag가 붙은 post가 일반적으로 더 많은 views**를 받는다고 Meta가 밝힘.
- Threads Insights는 likes/replies/quotes/reposts, follower growth, 국가/도시/연령/성별, 7~90일 비교, 발견 경로를 제공.
- 적격 Threads 게시물은 Instagram/Facebook 추천으로도 발견될 수 있음.
- bio에 최대 5개 링크를 넣고, 게시물/프로필 link click을 Insights에서 확인 가능.
- 긴 생각은 최대 10,000자 text attachment로 공유 가능하며 외부 원문 링크 연결도 가능.

## 3. 포맷별 실제 데이터

Buffer가 2026년 45M+ social posts를 분석한 자료를 초기 참고값으로 사용한다. 우리 계정 실제 데이터가 쌓이면 이 값보다 **우리 own cohort**를 우선한다.

### Threads

대략적인 median engagement rate:

```text
Video     5.55%
Image     4.55%
Text      2.79%
Link      2.34%
```

즉 Threads를 text-only 플랫폼으로 가정하면 안 된다. **영상/이미지가 스크롤 정지용으로 강할 수 있다.**

### Instagram

```text
Carousel median engagement / reach  6.9%
Single image                        4.4%
Reels                               3.3%
```

하지만 reach 관점에서는 Reels가 더 강함.

```text
Reels vs Carousel reach      약 1.36x
Reels vs Single image reach  약 2.25x
```

초기 운영 해석:
- **새 사람 도달**: Reels
- **기존 도달층의 깊은 반응/저장/공유**: Carousel

### Threads replies

Buffer의 128,000 Threads post 분석에서는 **댓글에 reply한 post가 engagement 약 42% 상승**한 것으로 보고됨. 모든 계정에 동일하게 보장되는 숫자는 아니지만, conversation-first 전략을 지지하는 강한 신호다.

- 원본 링크로 전환

중요: **남의 글 screenshot을 최소 변경해 올리는 전략과 다름.** 자기 원본 또는 사용 권한이 있는 자료 중심.

## 5. 공개 성장 사례

### 사례 A — KOSEN niche creator, 2026
공개 기록:

```text
Threads 12 → 1,073 (6개월)
2026-08-21 1,325
```

초기 daily posting, 이후 target을 매우 구체적으로 `KOSEN 진학을 고민하는 중학생 부모`로 좁힘. 실패담 post가 약 20K views, 이후 누적 28K. 게시 빈도를 늘린 뒤 100K-view post 발생.

핵심:
- 좁은 target reader
- 직접 reply/interaction
- 성공담보다 솔직한 실패/경험담
- 실제 Insights를 보고 audience를 다시 정의

## 6. 2026-09 한국 Threads 공개 트렌드 스냅샷

Threads 공개 데이터 분석 서비스 Throk의 당시 public ranking에서 상위 게시물은 대략 다음 유형이었다.

- 유명인/연예 조합·화제
- 동물 + 감정
- 생활 속 선행/후기형 human-interest story
- 지역 현상/사회 이야기
- 유명 기업/인물 관련 humor

이것은 **한 시점 snapshot**일 뿐 장기 전략의 증거는 아니다. 다만 한국 Threads에서 `사람 이야기 + 감정 + 놀람 + 유머 + 현재성`이 빠르게 반응을 얻는 후보군임을 보여준다.

- https://www.throk.ai/ko

## 7. 우리가 실험할 Content Format Taxonomy

### F01 — Text Hot Take
짧은 사실 + 강한 해석 1개.

### F02 — Text Explainer
`무슨 일 → 왜 뜸 → 그래서 뭐가 중요함`.

### F03 — List / Checklist
3~7개 항목으로 빠르게 소비.

### F04 — Question / Open Thread
독자가 자기 경험을 답하도록 설계.

### F05 — Original Screenshot Commentary
**우리 own 자료/허가 자료** screenshot + highlight + 추가 설명.

### F06 — Screenshot Evidence + Analysis
공식 발표/공개 UI/통계의 필요한 부분을 인용 범위 내 보여주고 분석. 원문 전체 대체 금지.

### F07 — Original Image Card
큰 headline + 핵심 수치/한 문장 + 출처/브랜드.

### F08 — Carousel
1장 hook → 2~6장 내용 → 마지막 결론/질문.

### F09 — Meme / Relatable
직접 제작 또는 권리 문제 없는 template. 계정 niche에서 벗어나지 않음.

### F10 — Chart / Comparison Card
가격/기능/전후/순위/데이터를 자체 그래픽으로 시각화.

### F11 — Short Vertical Video
9:16, 빠른 hook + context + payoff.

### F12 — Screen Recording Demo
AI tool/app/site 실제 사용 화면 + narration/caption.

### F13 — Talking / Voiceover Explainer
직접 voice 또는 허용된 synthetic voice + original script/visual.

### F14 — Long Text Attachment
짧은 본문 hook + 긴 text attachment + 필요시 외부 링크.

### F15 — Reply / Quote Response
잘 뜨는 conversation에 **새로운 정보/해석**을 추가하는 reply/quote.

### F16 — Poll / Binary Choice
단순 engagement bait가 아니라 실제 의견/수요 조사.

### F17 — Personal / Failure Story
구체적인 경험, 실수, 배운 점. generic motivational text 금지.

### F18 — Case Study
`전 → 행동 → 수치 → 배운 점`.

### F19 — Before / After
제품/작업/프로세스 변화 비교.

### F20 — Repurposed Own Content
우리 blog/video/report의 핵심 한 부분을 platform-native 형식으로 재가공.

## 8. Screenshot / 이미지 카드에 대한 결론

사용자가 언급한 `스크린샷 긁어서 글씨 조금 얹기`는 두 종류로 나눠야 한다.

### 적극 실험
- 우리 own blog/newsletter/post screenshot
- 공식 UI/공식 발표의 필요한 일부 + 분석
- 라이선스 확보 이미지
- public domain / 명시적 허용 자산
- 직접 만든 card/chart

### 기본 전략에서 제외
- 남의 viral post 전체 screenshot
- 남의 기사/블로그 내용을 screenshot으로 사실상 대체
- 영상/짤에 자막만 얹기
- 워터마크 제거/크롭/속도 변경 정도의 변형
- 같은 template에 원문만 갈아끼우는 mass production

특히 YouTube monetization은 2025년 `repetitious content`를 `inauthentic content`로 더 명확히 설명하며 mass-produced/repetitive content를 수익화 부적격으로 본다. reused content 역시 significant original commentary / substantive modification / educational or entertainment value가 없으면 위험하다.

- https://support.google.com/youtube/answer/1311392
- https://support.google.com/youtube/answer/12929256

## 9. Short Video 기준

YouTube 공식 자료에서 확인되는 방향:

- 첫 1초 hook이 매우 중요.
- 2025-03-31 이후 Shorts `view`는 재생 시작 기준이지만 YPP/수익 관련 비교에는 `Engaged views`가 중요.
- format 간 직접 비교보다 같은 format 내 성과 비교 권장.
- comments/replies를 Shorts로 다시 만드는 방식도 공식 creation workflow로 권장.
- non-original Shorts는 revenue sharing 부적격 가능.

초기 제작 구조:

```text
0~1s      hook
1~5s      무슨 일인지
5~20s     핵심 설명/증거
20~35s    의외점/결론
마지막     질문 또는 다음 콘텐츠 연결
```

영상 길이는 내용에 따라 더 짧거나 길 수 있으며 3분까지 Shorts가 가능하지만, 짧게 만들기 위해 핵심을 희생하지 않는다.

- https://support.google.com/youtube/answer/10059070
- https://support.google.com/youtube/answer/12942217

## 12. 지금 세울 초기 가설

1. Threads TH-A에서는 text-only보다 **image/video + text context**가 engagement가 높을 가능성이 있다.
2. Threads에서 post 작성 자체보다 **reply 활동이 account reach에 큰 비중**을 차지할 가능성이 있다.
3. 단순 link post보다 zero-click explanation 후 필요한 경우 link를 붙이는 쪽이 낫다.
4. topic tag가 가능한 글은 topic tag가 없는 동일 유형보다 reach가 높을 가능성이 있다.
5. TH-B에서는 Threads views보다 click/conversion이 실제 성공 기준이다.
6. Instagram 확장 시 Reels는 discovery, Carousel은 deep engagement 역할을 나누는 편이 유리하다.
7. Shorts는 viral raw views보다 Engaged views / subscriber conversion / revenue를 함께 봐야 한다.
8. screenshot 자체가 성과 포맷이 아니라 **screenshot + 명확한 해설/선택적 강조/원본 링크** 조합을 시험해야 한다.
9. 실패담/구체적 숫자/실제 경험은 generic 정보보다 conversation을 강하게 만들 수 있다.
10. 계정 identity 밖의 viral 소재를 억지로 따라가는 것보다 niche 안에서 trend를 번역하는 편이 장기 follower quality가 좋을 가능성이 있다.

## 13. 조사 결론

우리 시스템은 다음을 자동화해야 한다.

```text
실시간 소재 탐색
→ 실제 반응/상승속도 확인
→ 원본/권리/사실 검증
→ format 후보 2~4개 생성
→ 계정별 다른 가설로 제작
→ text / image / carousel / video / reply 실험
→ 실제 게시
```
