# 평가 반영 재작업 기록

2026-10-06 사용자 최신 지시의 범위는 실제 평가 기록을 읽고 전체 결과를 다시 검토·제작하는 작업이다. 단순 파일 생성 성공을 품질 완료로 처리하지 않는다.

실제 사용자 평가는 67건(점수 65건, 메모만 2건)이다. 글 ID와 기존 제작 버전에 연결했다. 고득점 글도 메모가 있으면 수정 대상으로 처리하며 이전 점수를 새 버전에 복사하지 않는다. 평가 원문·실제 소재·이미지는 공개 저장소에 올리지 않는다.

## 반영한 코드

- 글·도표 캡처를 작은 사진 표지에 넣고 본문에서 제외하던 처리를 수정했다. 제목 뒤 읽을 수 있는 본문으로 배치한다.
- 이미지와 함께 있는 `헉`, `이야`, 웃음·이모티콘만의 마지막 문구를 표시에서 제외하고 원문·제외 기록은 보존한다.
- 표시용 출처·사이트·조회 수 등 메타 문구를 분리했다. 이미지에 박힌 문구는 자동으로 제거했다고 주장하지 않는다.
- `7,000`처럼 숫자 안의 쉼표를 제목 강조 문구 구분자로 해석하지 않는다.
- 선택한 이미지 영역을 전부 기록해, 전체 원본으로 복원한 영역도 범위 감사가 정확하게 동작한다.
- Desktop 평가와 새 위치 평가를 ID·제작 버전별로 합치고 최신 시각을 유지한다. 두 원본의 백업을 남긴다. 손상 파일은 덮어쓰지 않는다.
- 재작업 입력의 `feedback-revision-plan.json`을 읽어 개별 제외·크롭·구성 기준을 적용한다.

## 제작·검증 범위

미방·무관한 이미지 5건은 사용자 메모에 따라 제외했고, 잘림을 지적한 2건은 이미지 전체 범위를 사용하도록 변경했다. 결혼식 원본은 한 문장뿐이므로 긴 내용을 복구했다고 주장하지 않는다. 짧고 미완성인 원문은 추가 확보가 필요하다. 재미가 없다는 평가는 자동 포맷 교정만으로 해결됐다고 처리하지 않는다.

표지 7개에 대한 이전 평가도 유지한다: 1은 기준 후보, 2·3은 과장 완화, 4는 중앙 두 인물을 유지하고 양옆 완화, 5는 보조 후보, 6·7은 재설계. 이번 작업에서 해당 첨부 원본을 직접 확보하지 못했으므로 이미지 수정 완료로 처리하지 않는다.
