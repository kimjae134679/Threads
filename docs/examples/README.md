# Production renderer examples

Both PNGs are 1080×1350 and were generated by `app/source-carousel.js` using the bundled regular/black fonts and the installed native Canvas runtime. They are actual code outputs, not image-generation mockups.

- `source-cover-image.png`: original source image `data/source-packages/theqoo-3826792703/original/01.jpg`, with the illustrative headline “결혼 승낙 뒤 / 밝힌 남편의 비밀”. The existing original pixels are scaled, not regenerated or blurred.
- `source-cover-text.png`: text transcribed from the user-supplied north/south-room reference, with headline “북향 vs 남향 / 차이가 이 정도?”. This is a demonstration of the text-only mode, not a claim that the underlying reference had no image.

Titles end at y=1120 with a 2px black stroke and no shadow. This native Canvas verification does not claim Windows/browser E2E, publication permission or original-source verification.
