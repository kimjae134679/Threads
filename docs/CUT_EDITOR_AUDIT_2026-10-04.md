# 자동 제작 점검 — 2026-10-04

현재 자동 제작은 검수 전 결과를 만드는 단계입니다. 자료 부족 항목과 외부 게시 여부를 구분하며 레퍼런스 전체와 같은 품질이라고 단정하지 않습니다. 최신 계획은 [Instagram 레퍼런스 기획](INSTAGRAM_REFERENCE_GUIDE.md)과 후보별 production-plan에 있습니다.

## 사용자 지적에 대한 조치

| 문제 | 수정 | 확인 |
|---|---|---|
| 제목이 작거나 위치가 불명확 | 안전 여백 64px, 제목 64~84px, 고대비 제목 영역과 3줄 제한 | 모든 417 계획의 여백·표지 겹침 검사 |
| 가로 사진을 세로로 늘려 공백 발생 | 비율 유지, 실제 내용량에 따라 높이 608~1350 | 2,886 PNG와 계획의 실제 크기 대조 |
| 본문이 없는 긴 장/중복 | 내용 기반 페이지 분할, 표지에서 소비한 본문·사진 중복 제거, 완전 중복 근거 기록 | 계획 회귀 테스트와 실제 대표 결과 확인 |
| 링크만 표시되는 장 | 본문·댓글 표시에서 URL 토큰 제외, 원문 ZIP과 계획에 보존 | 전체 계획의 URL 표시 검사 문제 0 |
| 자료가 실행에 바로 쓰이지 않음 | 저장 HTML/원문 TXT·JSON·미디어를 읽고 공개 기존 주소 보완 | 실제 1,084 후보 검사·417 제작 |
| 제작 여부·기준·게시 상태 불명확 | 버전·시각·원문 확인 시각·검수·게시 상태, 해시 기반 건너뛰기 | 같은 자료 재실행 417 건너뜀·새 제작 0 |
| 폴더와 구버전 혼재 | 현재 결과/제목__ID, 원문/작업 정보/참고 기록 분리 | 이전 파생 결과·예시·구버전 제거 |

## 실측

- 입력 1,084건, 검수 전 결과 417건·PNG 2,886장.
- 보류 667건: 원문 154, 접근 422, 정확한 주소 56, 이미지 4, 원문 선별 12, 원문 없음 14, 심한 소재 제외 5.
- 실패 0건. 실제 게시 확인 0건.
- 모든 ZIP/PNG SHA-256, 규칙 버전 2026-10-04.1, 실제 PNG 크기, 여백·제목 겹침·URL 표시 감사: 문제 0.
- 61개 테스트 suite와 문법 검사, 실제 Electron 자동 제작 UI smoke, 원문 선별 smoke 통과.
- 배포 0.3.1의 ASAR 주요 모듈·렌더러와 검증 소스 바이트 일치. 실제 실행 프로세스 확인.

417 결과의 원문을 모두 사람이 대조하거나 2,886 PNG를 전부 눈으로 검수한 것은 아닙니다. 제한 소스와 누락 자산은 보류합니다. 인스타 레퍼런스 샘플 확보·세부 관찰은 별도 문서의 확인 범위를 따릅니다. `publicationAllowed=false`이며 권리·개인정보·실제 게시 승인 상태를 생성 성공으로 바꾸지 않습니다.
