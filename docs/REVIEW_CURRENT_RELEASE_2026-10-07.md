# 수정본 전체를 현재 리뷰에 적용하는 규칙

사용자는 기존 제작물과 점수·메모를 과거로 옮기고, 수정하면 항상 전체를 새로 제작한 최신 결과만 리뷰에 보여달라고 요청했다.

`desktop/review-release.cjs`는 준비와 실제 적용을 분리한다. 전체 대상이 새 제작됐는지 확인하며 `already_done`, 제작 미완료, 장수·규칙·PNG·해시 오류를 거부한다. 모든 글 폴더를 전용 staging에 복사하고 바이트를 대조한 뒤, 새 검토 회차와 빈 평가 파일을 준비한다. 실제 적용 직전 기존 목록과 평가 해시가 바뀌지 않았는지 확인한다.

적용 시 D자료의 기존06결과·07평가·08재검토·09개별보완을 `05_이전 작업/리뷰 과거/before-<회차>`로 보관한다. 원본 입력과 바탕화면은 이동하지 않는다. 새 전체06·빈07을 적용하고 `review-current.json`을 갱신한다. 실패 시 이동한 폴더를 되돌리며 진행 기록이 남는다. 새 회차에서 이전 바탕화면 평가를 자동 가져오지 않는다. 이미지가 같아도 검토 회차가 다르면 점수 버전은 다르며 이전 화면의 점수 저장을 거부한다.

리뷰에는 새로 보기·과거 기록을 추가했고 기존 넘기기·1~10점·메모 자동 저장을 유지한다. 과거 점수는 현재 화면에 표시하지 않는다. 소스 변경은 전체 재제작→prepare→검증→activate→실제 리뷰 검수 순으로 전달한다. 별도 이미지나 HTML만 만들고 완료로 표현하지 않는다.
