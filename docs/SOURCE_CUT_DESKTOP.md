# Windows 자동 제작 프로그램 0.3.3

바탕화면 `Threads Cut Editor` 바로가기로 실행합니다. 기본 입력은 `Threads Cut Editor 자료/01_후보 기록`, 결과는 `06_자동 제작 결과/현재 결과`입니다. 기존 실행 동선을 유지했으며 새 도구는 설치하지 않았습니다.

저장 HTML, 원문임을 명시한 TXT/JSON, 실제 첨부 이미지, Source Package를 읽습니다. 공개 원문 보완은 기존 더쿠·인벤·네이트판 주소 대상입니다. [커뮤니티 입력 안내](COMMUNITY_SOURCE_INPUT.md)를 참고하세요.

## 제작 기준 2026-10-04.3

| 자료 | 기본 구성 |
|---|---|
| 실제 사진 | 사진 비율 유지, 하단 그라데이션과 큰 제목 |
| 긴 글 | 민트색 제목 표지, 원문 문단을 이어 배치 |
| 짧은 글 | 흰 바탕에 큰 제목과 원문 |
| 대화·글 화면 | 별도 제목 표지, 원본 화면 전체를 본문에 보존 |
| 설명형 | 제목과 원문·이미지를 순서대로 배치, 없는 설명을 추가하지 않음 |

폭 1080px, 안전 여백 72px, 본문 52px입니다. 제목은 형식과 길이에 따라 자동 조절합니다. 모바일 360px 표시에서 본문은 약 17px입니다. 사진과 캡처의 구분은 픽셀·배경·글줄 모양을 이용한 휴리스틱이며 OCR이나 의미 이해 모델이 아닙니다.

일반 세로 사진도 한 장에 비율을 유지해 담습니다. 긴 이미지는 빈 줄 경계에서 이어 나누고, 조금 긴 한 덩어리는 최대 20% 범위에서 폭을 조절합니다. 안전한 경계가 없으면 글자·말풍선을 임의로 절단하지 않고 선별 필요로 보류합니다. 원문 영상·오디오·임베드가 있으면 짧은 설명만 카드로 만드는 대신 원본 미확보로 보류합니다.

문단과 문장을 가능한 한 함께 배치하며 마지막 문장까지 보존합니다. 질문과 다음 답변은 한 장에 들어갈 때 함께 둡니다. 표지에서 사용한 사진, 완전 중복 본문·이미지, 표시용 URL·구분선 등은 제외 이유를 기록합니다. 실제 반응 근거가 있는 원문 댓글만 선택합니다. 캡처 속 글을 OCR로 재작성하지 않습니다.

기본은 내용에 맞춘 높이입니다. 원문 선별 화면에서 Instagram 4:5 또는 3:4를 선택하면 전 장을 1080×1350 또는 1080×1440으로 고정합니다. 제목 크기·위치 직접 조절과 폰트 선택도 지원합니다.

## 편집 계획과 상태

후보의 `작업 정보/editorial-plan.json`은 선택 입력입니다. schema는 `threads-editorial-plan-v1`입니다. templateId, coverSegmentId, coverTitle, titleEvidence, selectionReason, aspectRatio, regions, splitRows를 기록할 수 있습니다. regions와 splitRows는 원본 픽셀 좌표이며 원문을 실제로 대조한 뒤 지정합니다. 표지에 없는 사실을 넣지 않습니다.

제작 전 `제작 계획.md`와 production-plan.json을 저장합니다. 각 장의 목적·원문 ID·위치·사용 영역·분할 경계·제외 이유·검수 상태를 기록합니다. 원문 게시 시각·확인 시각·수집 시각·생성 시각을 구분하며 없는 시각은 미확인입니다.

원문·제작 규칙·원문 ZIP·PNG 해시가 같으면 건너뜁니다. 원문이나 편집 계획, 규칙이 바뀌면 다시 생성합니다. generated/already_done은 검수 전 결과입니다. 실제 게시 기록이 있는 항목은 재제작에서 제외합니다. 자동 게시 기능은 없습니다.

## 개발·재현

```sh
npm run check
npm run smoke:auto --prefix desktop
npm run smoke:curation --prefix desktop
npm run pack:win --prefix desktop
```

desktop/quality-review.cjs는 `--input 절대경로 --output 절대경로 --ids ID,ID`로 지정한 실제 후보를 분리된 사본에서 렌더링합니다. desktop/run-saved-batch.cjs의 `--saved-only`는 네트워크 보완 없이 전체 저장 자료를 처리합니다. desktop/audit-production.cjs는 결과 루트와 선택적인 감사 JSON 출력 경로를 받습니다. desktop/installed-smoke.mjs는 설치 실행본과 검증 출력 폴더를 받아 실제 모듈 로딩을 확인합니다.

## 0.3.3 처리 효율

계획과 렌더에서 이미지 디코딩·픽셀 분석·레이아웃 계산을 중복하지 않습니다. 캐시는 한 계획·3,200만 픽셀까지만 보관하며 제작 완료 또는 오류 때 해제합니다. 원문 ZIP 해시와 검수 조건은 계속 확인합니다. 픽셀 분석 변경은 이미지 후보의 재생성에만 반영합니다. 제목 수동 조절 체크 상태에 따라 크기·위치 입력을 활성화합니다.

검정 배경·노란 말풍선 원본에서 사진 오인을 확인하고 평탄 배경과 반복 글줄 근거가 있을 때 캡처로 분류하도록 고쳤습니다. 픽셀 분석 버전은 2026-10-04.4입니다. 바깥 여백도 행·열 전체가 공백일 때만 줄여 희미한 끝 문자를 보존합니다. 원문 ZIP·PNG 해시·본문 전체·이미지 연속성·가로 경계·PNG 높이를 실제 파일로 검사합니다.
