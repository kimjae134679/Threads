# Windows 자동 제작 프로그램 0.3.1

바탕화면 Threads Cut Editor 바로가기로 실행합니다. 첫 화면 '전체 자동 제작' 한 번으로 기존 자료 폴더를 검사합니다. 기본 경로는 바탕화면/Threads Cut Editor 자료/01_후보 기록입니다. 다른 자료는 '다른 폴더'로 선택합니다.

저장된 원문을 우선 사용하고, 체크된 공개 원문 보완 옵션은 더쿠·인벤·네이트판의 기존 주소만 대상으로 합니다. 새 소재를 발견하는 기능이 아닙니다. HTML/TXT/JSON과 저장 이미지, 기존 Source Package를 읽습니다. 상세 입력: [커뮤니티 원문 입력](COMMUNITY_SOURCE_INPUT.md).

## 사람이 보는 순서

앱에서 상태 카드 → 제목 검색 → 후보별 사유·제작일·기준 버전·검수·게시 상태 → 표지 보기/결과 폴더로 이어집니다. 제작된 결과가 기본 목록입니다. 보류 목록에는 다음 조치를 표시합니다.

PC 자료:
- 00_먼저보기: 실행 안내와 원문 입력 방법.
- 01_스타일 레퍼런스: AAA 원본과 참고 기준.
- 01_후보 기록: 후보별 원문 source/, 제작 계획.md, 자료 안내.txt, 작업 정보/, 참고 기록/.
- 03_배포 설치파일: 현재 실행본과 배포 ZIP.
- 06_자동 제작 결과: 자료 목록.html·status.csv·status.json, 현재 결과/제목__ID/.

결과 폴더에는 source-bundle.zip(원문), review-preview.zip(검수 전 결과), rendered/장별 PNG, production-plan.json(실제 사용 계획)이 있습니다. 최신화 완료 후 이전 제작본·구버전 설치파일·임시 예시를 삭제합니다.

## 제작 기준 2026-10-04.1

수집 전 제목·본문·이미지·댓글 규칙을 기록하고, 제작 전 장별 계획을 저장합니다. 표지 제목은 원제에서 근거가 있는 부분을 골라 짧게 배치하며 원제 전문은 보존합니다. 제목 64~84px, 본문 46px, 안전 여백 64px. 표지 하단에 고대비 제목을 놓습니다.

가로 사진에 무조건 1350px 높이를 붙이지 않습니다. 내용에 따라 1080×608~1350으로 정합니다. 본문 사진은 순서와 비율을 유지하고, 긴 사진은 원본 전체를 균등 분할합니다. 표지에서 이미 충분히 보인 사진·본문은 불필요하게 되풀이하지 않습니다. 본문·댓글의 URL 문자열, 완전 중복, 구분선과 일부 안내 문구는 표시에서 제외하고 원본과 제외 이유를 계획에 보관합니다.

없는 이미지·본문·댓글은 만들지 않습니다. 시스템 폰트 대체는 자동 제작에서 원문의 기호·이모지를 보존하기 위해 기록하며, 수동 편집의 엄격한 폰트 검증은 유지합니다. 글이 너무 길거나 원문 영역이 불확실하면 제작 보류로 표시합니다.

## 재실행과 상태

원문·적용 기준·원문 ZIP·PNG 해시가 같으면 이미 제작됨으로 건너뜁니다. 이미지가 삭제되거나 원문·기준이 바뀌면 다시 제작합니다. 중지한 뒤 재실행해도 완료 기록을 보존합니다. 다른 창의 동시 제작은 잠금으로 막습니다.

generated/already_done은 검수 전 제작 결과입니다. 검수와 게시 상태를 별도 표시합니다. 명시적인 게시 URL·시각이 있는 published 항목은 재제작에서 제외합니다. 현재 후보에 외부 게시 확인 기록이 없으면 게시 여부는 미확인입니다.

각 장의 크기가 달라질 수 있으므로 게시 도구에서 사용하는 최종 비율은 실제 게시 검수 단계에서 확인합니다. 앱이 자동 게시하지 않습니다.

## 2026-10-04 실제 확인

1,084건을 검사해 검수 전 결과 417건·PNG 2,886장을 만들었습니다. 나머지 667건은 원문·접근·주소·이미지·선별 등의 확인이 필요합니다. 실패 상태는 0건입니다. 전체 결과의 파일 해시·기준 버전·크기·안전 여백·표지 겹침·URL 표시를 검사했고 문제는 없었습니다. 같은 자료를 다시 실행하면 417건을 건너뛰며 새 결과를 중복 생성하지 않습니다. 전체 이미지를 사람이 눈으로 검수했다는 뜻은 아닙니다.

JavaScript 문법과 61개 테스트 suite, 실제 Electron 자동 제작 UI smoke를 통과했습니다. Windows의 일시적인 파일 잠금은 고유 임시파일과 제한된 재시도로 대응하고, 지속적인 쓰기 권한 오류를 성공으로 처리하지 않습니다.

## 개발·검증

```sh
npm run check
npm run smoke:auto --prefix desktop
npm run smoke:curation --prefix desktop
npm run pack:win --prefix desktop
```

smoke:auto는 분리된 임시 자료로 TXT/JSON·HTML·저장 이미지, 실제 UI 버튼, 재실행 건너뛰기, 접근 보류를 확인합니다. 사용자 원본을 테스트로 변경하지 않습니다. 실제 자료 대량 처리는 desktop/run-saved-batch.cjs로 별도 실행합니다. 원문 선별 검사는 8장의 실제 원본이 빠짐없이 쓰이는지, 불필요한 아래 여백, 검수 전 최종 출력 차단과 원본 변경 거절을 확인합니다.
