## 사용과 자동 처리

앱을 열면 저장 자료를 자동으로 읽습니다. 목록은 글 제목, 한국어 상태, 첫 장 미리보기와 보류 이유를 보여 줍니다. 각 글의 원본 열기·전체 이미지 보기·결과 폴더 열기를 따로 사용할 수 있습니다. 전체 결과 폴더도 바로 엽니다.

`전체 이미지 만들기`로 저장된 모든 자료를 처리합니다. 원문·편집 계획·제작 규칙·PNG 해시가 같은 완성 결과는 건너뜁니다. 입력이나 계획이 바뀌면 다시 만듭니다. 실제 표지 파일이 없으면 완료로 표시하지 않습니다. 진행과 재실행은 실제 파일을 기준으로 확인했습니다. 자동 게시 기능은 없으며 생성 완료는 검수 승인과 다릅니다.

저장 HTML, 원문임을 명시한 TXT/JSON, 실제 첨부 이미지와 Source Package를 읽습니다. 공개 원문 보완은 기존 더쿠·인벤·네이트판과 뽐뿌 www의 정확한 공개 글 주소 대상입니다. 뽐뿌는 실제 공개 원문·이미지 2건을 확보했고 1건 제작, 1건 이미지 분할 선별 보류를 확인했습니다. 이를 기존 입력에 반영한 뒤 전체 재제작했습니다. 접근 제한이나 없는 원문은 이유를 표시하고 보류합니다. 디씨·블라인드는 저장 자료 입력으로 처리하며 자동 접근 제한 해제를 주장하지 않습니다. [커뮤니티 입력 안내](COMMUNITY_SOURCE_INPUT.md)를 참고하세요.

`저장한 웹 글 가져오기`에서 HTML/HTM·원문 TXT/JSON을 여러 개 선택하면 목록에 등록됩니다. HTML과 같은 이름의 `_files` 폴더 또는 `media` 폴더를 함께 두세요. 가져온 뒤 `전체 이미지 만들기`를 누릅니다. 같은 원문은 중복 등록하지 않으며 이미지가 빠졌으면 보류 이유를 표시합니다. 댓글이 화면에 실제 표시된 뒤 저장해야 합니다. 내장 가져오기는 로그인 쿠키나 브라우저 세션을 복사하지 않습니다.

## 이미지 구성

폭 1080px, 안전 여백 72px, 본문 52px입니다. 제목 전체를 유지하면서 길이에 따라 크기를 조정합니다. 표지 줄바꿈과 핵심어 강조를 직접 지정할 수 있습니다.

| 자료 | 구성 |
|---|---|
| 실제 사진 | 사진·그라데이션·큰 제목·노란 핵심어 강조 |
| 글이 있는 사진·도표·캡처 | 원본 전체를 위쪽에 보이고 아래 진녹색 영역에 큰 제목; 사진 위 글을 덮지 않음 |
| 긴 글 | 민트색 제목 표지와 이어지는 원문 문단 |
| 짧은 글 | 민트 바탕·장식 요소·큰 제목과 핵심어 색 강조 |
| 글·대화 캡처 | 제목 표지와 원본 화면; 의미 있는 글을 임의로 재작성하지 않음 |
| 혼합 자료 | 원문 글과 실제 이미지를 원래 순서로 배치 |

사진 판별은 픽셀·배경·글줄 모양을 보는 휴리스틱입니다. 소재의 의미까지 자동으로 판단하지는 않습니다. 사용자가 선택한 원문 장식 사진도 표지로 쓸 수 있으나 실제 사건 현장·인물 사진이라고 주장하지 않습니다. 이번 이미지 표지는 97건이며 사진뿐 아니라 도표·캡처를 포함합니다. 대표 20건은 원문을 읽고 제목 근거와 적합한 사진을 별도로 지정했습니다. 로또 꿈을 실제 당첨처럼 표현하거나 메뉴 사진을 음식 사진처럼 쓰던 선택을 바로잡았습니다.

긴 이미지는 실제 빈 줄 경계에서 나누고 안전한 경계가 없으면 선별 필요로 보류합니다. 마지막 이미지 조각과 짧은 설명을 가능한 한 같은 장에 둡니다. 인기 댓글은 원문 반응 근거가 있는 것만 선택합니다. 일부 원본 캡처의 작은 글씨와 내부 UI는 추가 시각 검수가 필요합니다.

원문 글·공백·줄바꿈과 원본 이미지는 source-bundle.zip에 보존합니다. 이미지 조판에는 줄 감싸기가 적용됩니다. 파일 감사의 텍스트 대조는 공백을 제외한 문자 연속성을 확인하며, 원본 공백·줄바꿈의 시각적 일치 전체를 증명하지 않습니다.

## 후보별 편집 계획

`작업 정보/editorial-plan.json`의 schema는 `threads-editorial-plan-v1`입니다. templateId, coverSegmentId, coverTitle, titleEvidence, titleEvidenceNotes, coverLines, titleHighlights, selectionReason, aspectRatio, regions, splitRows, exclusions를 사용할 수 있습니다.

titleEvidence는 실제 원문 인용이며, 제목에서 강조할 문구는 제목에 존재해야 합니다. regions와 splitRows는 직접 확인한 원본 픽셀 좌표입니다. exclusions는 원본 ID와 제외 이유를 기록합니다. 명시적으로 제외한 장식 사진과 UI 영역도 원문 ZIP에는 남깁니다. 이번 취향은 [사용자 표지 기준](USER_COVER_PREFERENCES_2026-10-05.md)에 고정했고 20건의 계획은 [편집 근거](QUALITY_EDITORIAL_EXAMPLES_2026-10-05.json)에 있습니다.

각 결과는 production-plan.json, 원문 ZIP, 검수 ZIP, PNG와 `이미지 전체 보기.html`을 포함합니다. 계획에는 원문 ID·사용 영역·분할 경계·제외 이유를 기록합니다. 원문 게시·확인·수집·생성 시각은 구분하고 없으면 미확인입니다.
