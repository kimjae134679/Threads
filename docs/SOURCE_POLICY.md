# Source Policy

공개되어 있다는 사실만으로 자동 수집·상업적 복제·재업로드가 허용되는 것은 아닙니다. 이 프로젝트는 소스를 다음처럼 구분합니다.

## GREEN — 기본 사용 가능

- 정부/공공기관/기업의 공식 공개자료
- 공식 API와 제공자가 공개한 RSS/Atom
- 직접 제작한 글·사진·영상·음원
- 상업 이용 조건이 명확한 라이선스 자료
- Public Domain 및 조건을 확인한 CC 자료
- 제3자 권리를 침해하지 않는 자체 AI 생성 자산
- 사용자가 직접 제공한 주제·메모·URL을 새 콘텐츠 제작 참고자료로 쓰는 경우

API/라이선스의 저장·재배포·표시 조건은 별도로 지킵니다.

## YELLOW — 참고 가능, 사람 검토 필요

- 일반 뉴스 기사
- 공개 블로그 글
- 공개 SNS 게시물
- 이용 조건상 상업적 재사용 범위가 불명확한 공개 자료
- 약관 확인이 필요한 공개 커뮤니티 게시물

기본 허용 범위는 URL/출처 메타데이터 저장, 사실 확인, 필요한 최소 인용, 여러 소스를 종합한 자체 해설·비교·분석입니다.

기사/게시글 전체 복사, 전체 캡처 재게시, 원문을 AI로 표현만 바꾼 뒤 원본 콘텐츠로 취급하는 방식은 사용하지 않습니다.

## RED — 자동수집 대상에서 제외

### 디시인사이드

2026-07-21 시행 이용약관은 robots.txt로 허용한 일부 사이트 외에는 회사의 사전 서면 동의 없는 크롤링을 금지한다고 명시합니다. 따라서 인기글 봇, 갤러리 대량 수집, 게시글/댓글 DB화를 기본 기능으로 만들지 않습니다.

사람이 개별 공개 URL을 소재 후보로 넣더라도 원문 재게시가 아니라 위험 검토 후 자체 재구성만 합니다.

### Blind

Blind/Teamblind 약관은 명시적 허가 없는 crawling, scraping, data mining, data extraction, reproduction/copying 등을 제한합니다. Blind 역시 자동수집 대상에서 제외합니다.

### 로그인·회원등급·폐쇄형 커뮤니티

가입/등급/친구공개/비공개/유료구독/초대가 필요한 자료는 별도 허가 없이 자동수집하지 않습니다. 여성시대 등 개별 커뮤니티도 해당 시점의 약관과 접근정책을 확인하기 전에는 자동수집 목록에 넣지 않습니다.

### 권리 없는 완성 콘텐츠

방송·영화·드라마·애니·스포츠 중계·다른 크리에이터의 영상·출처 불명 짤을 내려받아 자막, 테두리, 속도 조정 정도만 하고 재업로드하는 방식은 기본 전략에서 제외합니다.

## 커뮤니티 사연을 쓰는 방식

원문은 `소재`이지 최종 상품이 아닙니다. 결과물의 가치는 사건 흐름 재구성, 맥락 설명, 사실 확인, 쟁점 분류, 반응 요약, 자체 관점에서 나오게 합니다.

기본 제거 대상:

- 닉네임/ID/IP
- 실명·전화·이메일
- 상세 직장/부서·주소·학교
- 얼굴·차량번호
- 여러 단서를 합치면 일반인을 특정할 수 있는 정보

익명 게시물의 범죄·불륜·사기·갑질 같은 주장은 독립 검증 없이 사실처럼 단정하지 않습니다. 댓글도 대량 복제보다 찬반 논리와 주요 반응을 자체 문장으로 요약합니다.

## 뉴스/이슈 사용 규칙

우선순위는 `공식 1차 자료 → 신뢰 가능한 복수 보도 → 당사자 공식 발표 → 공개 반응`입니다.

기사는 기사 문장을 재판매하는 재료가 아니라 사실 확인용 소스입니다. 최종 콘텐츠에는 무엇이 새 소식인지, 왜 중요한지, 이전과 무엇이 달라졌는지, 독자에게 어떤 의미인지 같은 추가 가치가 있어야 합니다.

## 이미지·영상 자산 우선순위

1. 직접 촬영/제작
2. 자체 그래픽·차트
3. 상업 이용 가능한 라이선스 자산
4. Public Domain
5. 조건을 지킨 CC
6. 제3자 권리를 침해하지 않는 AI 생성 자산
7. 플랫폼이 공식 제공하는 Remix/Quote/Repost 기능

Google 이미지 검색 결과, 출처 불명 밈, 워터마크가 있는 타 플랫폼 영상, 방송/영화/스포츠 클립, 다른 크리에이터 완성 영상은 별도 권리 확인 없이 재사용하지 않습니다.

## `출처를 적으면 괜찮다`는 기준은 사용하지 않음

출처 표시는 필요할 수 있지만 그것만으로 이용허락이 생기지는 않습니다. 이용허락, 인용 범위, 상업적 이용 가능 여부, 플랫폼 약관은 각각 확인합니다.

## AI 재작성 기준

안전한 변환으로 보지 않는 흐름:

`원문 복사 → AI 말투 변경 → 문장 순서 변경 → 게시`

우리가 원하는 흐름:

`여러 출처에서 사실 추출 → 검증 → 핵심 질문 선정 → 새 구조 설계 → 자체 설명/분석/비교 추가 → 직접/허가된 시각물 제작 → 플랫폼별 결과물 생성`

## Research Bundle에 저장할 권리 필드

```text
source_url
source_type
collection_method
terms_status
commercial_reuse
quote_scope
asset_license
attribution
privacy_risk
defamation_risk
manual_review_required
notes
```

권리 정보가 비어 있으면 원본 영상/이미지를 자동 재사용하지 않습니다.

## 기본 판정

- GREEN: 자동 연구 파이프라인 진입 가능
- YELLOW: 연구 후보 가능, 발행 전 사람 검토
- RED: 자동수집 차단
- UNKNOWN: 약관 확인 전 대량수집 금지

이 문서는 법률 자문을 대신하는 것이 아니라, 프로젝트가 무단 대량복제 중심으로 설계되는 것을 막기 위한 운영 기준입니다.
