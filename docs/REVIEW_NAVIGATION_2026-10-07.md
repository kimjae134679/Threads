# 게시글 평가 화면 · 이동 편의 개선

기존 한 장씩 넘기기·아래로 읽기·1~10점·메모 저장 방식을 유지하며 이동 조작을 보완했다.

- 하단 고정 이전/다음 글·장 버튼과 평가·메모 바로가기.
- 좌우 키는 장, 위아래 키는 현재 검색/분류 목록의 글. 입력란·메모 편집 중 이동하지 않음.
- 세로 스크롤을 가로 스와이프로 잘못 처리하지 않도록 방향과 포인터를 확인. 이미지 밖에서 놓아도 실제 포인터 캡처로 동작.
- 글 이동 전 저장 완료; 빠른 선택은 마지막 요청 적용; 돌아온 글의 페이지 기억; 인접 장 미리 읽기.

검증: 220파일 문법, 전체70회귀묶음 통과. 실제 숨김 Electron 평가 화면25검사 통과(점수1/10·메모·저장·닫기·재열기·새 버튼·키·실제 마우스 스와이프·필터 경계·빠른 선택). 검사는 별도 복사한3글과 평가 기록만 사용했다. Windows에서 D작업본과 C임시 폴더의 드라이브 차이로 기존 렌더링 검사가 처음 실패해 이번 실행의 TMP/TEMP만 D검사 폴더로 설정한 뒤 전체를 통과했다. 테스트를 삭제하거나 완화하지 않았다.

사용자 실행 파일은 `D:\A_KJ\AI\Applications\ThreadsReview\0.3.14\Threads Cut Editor.exe`, 바로가기는 `D:\A_KJ\AI\Launchers\Threads 게시글 평가.lnk`이다. 기존 설치·바탕화면·원본·평가67건을 보존한다. 이번 리뷰 조작 개선은399글의 전체 품질 보완 완료와 다르다. 실행 파일의 제작 데이터 기본 위치는 기존 D자료 폴더다. 두 개별 보완본은 여전히 별도 D09 자료이며 전체 재제작판으로 합쳐졌다고 주장하지 않는다.
