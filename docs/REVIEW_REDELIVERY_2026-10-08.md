## 실제 적용 방식

`scripts/deliver-fresh-review-20261008.cjs <고유회차>`는 기존 입력 원본의 별도 스냅샷을 만들고, 빈 출력 폴더에서 399글 전체를 실제 Electron으로 재생성한다. 전체 PNG 해시·서명·폭·장수·계획 규칙과 복사 바이트를 확인하고, 독립된 검증 자료에서 넘기기·세로 읽기·점수/메모 저장·새로 고침·닫고 다시 열기를 검사한다.

검증 이후 현재 결과와 평가를 `05_이전 작업/리뷰 과거/before-<회차>`로 옮기고 새 결과와 빈 평가 파일을 적용한다. 제작 중 사용자 평가가 바뀌면 적용을 중단한다. 과거 평가 67건의 원본 해시는 그대로 확인한다. 바탕화면, 원본 미디어, 다른 프로젝트를 수정하지 않는다.

## 추가로 고친 표지

직접 확인한 원본 편의점 사진에 간판 글자가 있다는 이유로 글 캡처로 분류돼, 사용자가 선택한 사진 표지가 단색 제목으로 바뀌었다. 해당 글의 편집 계획에 `imageRoles.s0 = photo`를 지정해 실제 사진을 복구했다. `coverSegmentId=s0`, 사진 전체를 보여주는 panel 구성, 사용자가 고른 두 강조 표현을 유지한다. 원본 사진 바이트와 본문은 수정하지 않았다. 실제 사건 장소라는 주장은 하지 않는다.
