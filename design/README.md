# 업로드 도안 · 사용자 확인 대기
upload-desktop-mockup.html은 단일 파일이며 로컬 브라우저에서 열 수 있습니다.
예시 게시물·5장 캐러셀·캡션·Instagram/Threads 선택·대기 목록·라이트/다크 전환을 보여 줍니다.
모든 데이터는 예시. 계정 미연결·게시 미승인 상태이며 로그인·OAuth·업로드·게시·예약 기능은 없습니다.
외부 리소스와 네트워크 요청 없이 구성했습니다. CSP connect-src 'none'.
기존 제작·리뷰 공유파일은 수정하지 않았습니다.
기존 도구는 Threads/threads.mjs(공식 텍스트 API), instagram.mjs(이미지/캐러셀 dry-run), publication-journal.mjs(중복·재시작)에서 확인했습니다.
작성한 core와 테스트는 보존하고 사용자 도안 확인 전 기능 구현은 보류합니다.
PC 초기화 오류·Desktop Commander 월 한도로 D드라이브와 로컬 .agents/skills는 미확인입니다.
로컬 파일 브라우저 열기는 보안 정책이 차단하여 우회하지 않았습니다. 실제 화면 캡처와 PC 적용은 미완료입니다.

정적 PNG 시안: upload-desktop-design.png. ImageGen으로 만든 시각 방향 제안이며 HTML 실제 화면 캡처가 아닙니다. HTML과 이미지 사이에 세부 차이가 있습니다. 실제 캡처는 로컬 브라우저 렌더링 경로가 복구된 뒤 확인해야 합니다.
